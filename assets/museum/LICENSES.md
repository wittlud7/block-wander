# 馆藏图片来源与许可

当前游戏的 18 张作品均为真实历史艺术品的博物馆数字图像，不是 AI 生成图。

- 提供机构：The Cleveland Museum of Art（克利夫兰艺术博物馆）。
- 官方开放政策：https://www.clevelandart.org/open-access
- CC0 1.0：https://creativecommons.org/publicdomain/zero/1.0/
- 核验日期：2026-10-25。每幅官方 API 记录的 `share_license_status` 均为 `CC0`，且馆方提供实际 `images.web.url`。不是仅凭元数据的开放状态判断图像许可。
- 馆方允许下载、改编、分享和商业再利用这些 CC0 图像。博物馆商标及第三方其他权利不随图片许可转让；本项目不表示馆方背书。
- 图像仅作缩放、等比例居中补米色边与 JPEG 压缩；完整保留原图，没有裁切、重绘或 AI 修改。所有输出为 900 × 900。
- 中文作品名为本项目的翻译或简写；原文标题、英文作者信息、日期、登录号、原图哈希与 API 地址见 `manifest.json`。
- 主题是浏览分组；并不宣称同组所有作品严格属于完全一致的艺术史分类。
