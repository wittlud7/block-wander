# 手机微信小游戏开发版

## 已实现

原生Canvas首页、六类艺术/18幅馆藏、难度和关卡选择、无尽与积分换块、每日同题本机纪录、收藏导出预览、音效、作品来源、隐私说明、清空本机记录。使用触摸与安全区域布局，支持滑动列表、切后台取消拖动和分模式续玩。

该入口没有DOM或webview。底层引擎与网页版共用，手机操作通过 `wx.onTouch*` 接入。菜单与游戏画布共同避让顶部胶囊区域；图片按需加载，最多保留12幅，当前游戏主题的三幅作品优先保留。

## 生成与打开

```sh
npm run wechat:pack
```

用微信开发者工具以“小游戏”类型打开生成的 `output/wechat/block-wander/`。默认AppID为 `touristappid`，是开发预览配置。若已有真实小游戏AppID，先设置环境变量 `WX_APPID` 再重新打包。

PowerShell示例：

```powershell
$env:WX_APPID='你的真实小游戏AppID'
npm run wechat:pack
```

不要将AppSecret、会话密钥或服务端访问令牌写入客户端或提交Git。打包脚本只接收AppID。

打包采用白名单，包含源代码、18幅真实CC0馆藏和许可说明，约3.32MB；脚本以4MiB预算做检查。微信工具最终编译体积仍需实测，超过限制再拆分素材。

## 浏览器模拟验收

```sh
npm start
```

打开 `http://127.0.0.1:4186/scripts/wechat-preview.html` 可查看同一份 `game.js` 在wx接口模拟器中的手机画布。模拟器仅用于触摸、布局和流程检查，不等同于微信开发者工具或真机验收。

`scripts/verify-native-mobile.js` 使用真实指针事件检查：首页、六类主题、选择难度、拖放、刷新续玩、通关、原生收藏导出、无尽、积分换块、音效、清空数据及320/375/430宽度。模拟器存档使用独立的 `wx-preview:` 前缀，不覆盖网页游戏数据。

## 正式提交前仍需完成

- 真实AppID和主体后台配置；在微信开发者工具及iOS/Android真机测试冷启动、内存、触控、胶囊、安全区域、图片预览/保存、前后台和离线行为。
- 微信登录身份与服务端校验、配置合法HTTPS域名并接入在线榜单。当前每日挑战仅保存本机完成纪录，界面已明确标注，不展示虚构在线玩家。
