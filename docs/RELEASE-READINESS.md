# 发布评估 · 2026-10-25

## 当前结论

适合提交GitHub并作为网页MVP开放试玩。当前功能包括真实馆藏艺术闯关、无尽与积分换块、每日同题、真实榜单、收藏导出、本机续玩和删除排名资料。52项自动测试及浏览器主要路径通过，生产站点28个静态文件已与源码比对。测试与源码记录见 `VALIDATION.md`。

这不等同于完成微信正式上线，也不代表已经经过规模化运营或真人难度验证。正式运营前仍需真实用户试玩、低端设备性能检查、线上错误监控和接口限流策略；目前没有支付、广告、云端章节同步或无尽全球排名。

## 微信小游戏状态

本工程是Canvas小游戏，原生入口为 `game.js`，工程类型为 `game`，不是把网页直接嵌入普通小程序。共享游戏引擎可复用，已有触摸、安全区域、存档和图片预览适配；当前原生入口主要开放默认三幅作品的章节路径。

尚未完成的微信工作：

1. 将网页首页、六类作品、无尽入口、收藏和设置移植到原生交互层，完整接通模式切换；当前微信包不声称包含网页版全部页面。
2. 将网页访客Cookie身份改为微信登录身份，服务端验证微信身份；使用适合微信环境的HTTPS接口与后台配置的合法域名，接入每日榜单。不能直接假定Sites浏览器身份和Cookie方案适用于微信。
3. 配置真实小游戏AppID，并在微信开发者工具与iOS/Android真机完成触控、图片导出、存档、冷启动、内存、切后台与网络异常验证。
4. 在主体后台核对适用的类目、隐私、备案、资质和审核材料后提交体验版/审核；相关要求以该主体当时的微信后台和官方规则为准，本工程不代替资格审核。

## 可复现的微信开发包

```sh
npm run wechat:pack
```

生成 `output/wechat/block-wander/`。用微信开发者工具打开该目录可检查原生章节入口。默认保留 `touristappid`，只作为开发预览；提供环境变量 `WX_APPID` 可写入自己的AppID。AppID不是AppSecret，不需要将AppSecret写入客户端。

打包采用文件白名单，只包含原生入口、共用模块和18幅CC0馆藏及来源清单，检查本地总文件体积不超过4MiB预算。最终上传体积以微信开发者工具为准，超过平台限制时应分包或远程加载。这个预算检查不能代替真机测试或审核。

## GitHub交付

默认建立私有 `block-wander` 仓库。提交完整游戏、网页、服务器、Sites构建源、SQL迁移、馆藏许可和测试，保留共享引擎结构方便继续做微信适配。

不提交本机访客排名、Cookie、访问令牌、Git凭证、环境文件、依赖、构建缓存、截图、历史AI图片或Sites源码仓库的嵌套Git元数据。Sites项目ID不是凭证；配置保留当前项目身份，但复制项目到新账号发布时应使用新Site身份。

代码目前未指定开源许可证；私有上传不等同于公开开源。馆藏图片的CC0许可独立，详情见 `assets/museum/LICENSES.md`；第三方依赖遵守各自许可。
