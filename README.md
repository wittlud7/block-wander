# 方块漫游

自写代码采用 MIT 许可；真实馆藏图像采用 CC0，第三方代码保留原许可。详见 [LICENSE](LICENSE) 与 [NOTICE](NOTICE.md)。

艺术闯关、无尽挑战、每日同题。空棋盘开局，填满整行或整列即可消除。

## 运行与检查

Node.js 22.13+，主项目无额外运行依赖：

```sh
npm start
npm run check
npm test
```

本机地址 http://127.0.0.1:4186/ 。本机排名写入 `.data/rankings.json`，不进入发布源和交付包。

## 玩法

- 艺术闯关：六类艺术、18幅馆藏、每幅六关，共108关。轻松不限步数，标准28–38步，大师24–34步；大师含需消除两次的加固格。揭开目标格数并覆盖所有标记位置即通关。
- 无尽挑战：无步数、时间或揭画目标。三个备选方块都放不下才结束；方块随机供给，不保证每组可解。
- 无尽积分：每消一条行列赚25积分，清空额外赚50。选中一块再点换块，首次100积分，以后每次增加50；换为当前能放置的其他形状，得分不扣除。积分仅在本局使用，开新局归零。
- 所有模式失败后都不能撤回或换块复活。无尽模式全程不提供撤回或提示，闯关进行中仍可使用有限撤回和提示。
- 每日同题：北京时间切日、统一标准题目，服务端重放验证，按步数、提示、撤回、得分、时间比较，每人每天只保留最好成绩。无尽最高分为本机纪录，不混入每日排行榜。

闯关和无尽分别保存棋盘，切换模式不会覆盖另一局。主题改变外观，不改变玩法；同一模式的主题切换保留棋盘。章节、收藏、本机最高分和积分保存在浏览器，当前不提供跨设备章节同步。

拖放或点选放置。键盘1/2/3选块、方向键移动、空格放置、U撤回（仅进行中的闯关）、R重开、M音效、Esc取消。首页和输入框不响应游戏快捷键。

## 素材与许可

当前页面和游戏使用18幅真实历史馆藏图像，不使用AI生成图片或材质。克利夫兰艺术博物馆官方记录逐幅标注图像CC0；并非仅判断元数据或作品年代。分组包括印象派、后印象派、新艺术、浮世绘、象征主义、中国山水。

完整作品保持比例，缩放、补边并压缩；中文标题为本项目翻译或简写。游戏来源页和导出作品保留作者、年代、馆藏与许可。博物馆标志不纳入素材许可，也不表示馆方背书。

## Sites 与交付

`sites-app/` 是Vinext/Cloudflare Worker发布源，复用原Site身份和D1。以根目录源码为准，再同步构建：

```sh
npm --prefix sites-app ci
npm run site:sync
npm --prefix sites-app run build
npm run release
```

同步包含网页、共享规则、18幅馆藏和许可清单。旧AI素材在开发档案中保留，但不进入当前Sites发布或v9源码包。源码包为 `output/release/block-wander-v9.zip`，排除依赖、构建缓存、本机数据、凭证与Git元数据。GitHub交付使用独立源码仓库，保留Sites项目的构建源。
